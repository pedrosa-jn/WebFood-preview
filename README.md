# Cuaderno de recetas

A static recipe site built with HTML, CSS, and JavaScript. It can be hosted directly with GitHub Pages.

## Local preview

Open `index.html` in a browser. The category page is `categoria.html`.

## Content

Recipe entries are maintained in `data/recetas.js`. Recipe images can be added under `images/` and referenced by their relative path in that data file.

## GitHub Pages

The preview site is served from the repository root on the `main` branch.
